# StoreTrack

## Retail Sales Dashboard for a Neighbourhood Store

StoreTrack is a Python-based retail sales management system designed for a small neighbourhood store. It helps manage products, process customer sales, update stock, store sales records, and analyse sales performance using Pandas and Matplotlib.

## Features

- View product catalogue
- Add new products
- Search products
- Manage stock
- Generate itemised customer bills
- Calculate discounts
- Calculate GST
- Generate invoice numbers
- Store sales history in CSV
- Store product and stock information in JSON
- Analyse daily and monthly revenue
- Identify best-selling products
- Analyse category-wise sales
- Generate sales visualisations
- Generate a 2×2 sales dashboard
- Handle invalid inputs and out-of-stock situations

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV
- JSON
